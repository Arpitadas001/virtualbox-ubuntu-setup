## VirtualBox and Ubuntu Setup

## Objective
Download and install Oracle VirtualBox, download Ubuntu, and create an Ubuntu virtual machine.

## Work completed
- Opened the VirtualBox download page.
- Downloaded the Ubuntu desktop image.
- Created an Ubuntu virtual machine in VirtualBox.
- Checked the virtual machine settings.
- Started Ubuntu and updated its software.
